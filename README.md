# DECK ODDS — 遊戯王 デッキ確率計算機

遊戯王の初手確率と、初動札・事故札のバランスから40〜60枚のデッキ構築を比較できる、**単一HTMLファイル**の無料Webアプリです。

## 含まれる機能

- 初手で対象カードを1枚以上引く確率（先攻5枚・後攻6枚・任意のドロー枚数）
- 0枚・1枚・2枚・3枚以上の確率、およびデッキ枚数別早見表
- 初動札と事故札が共存する場合の「初動あり・事故なし」確率
- 事故札を引いても残る手札の評価（0〜100%）を考慮した、40〜45・40〜50・40〜60枚の比較
- デッキ枚数別グラフと比較表
- 現在の設定を含むURLのコピー（GitHub Pagesなどで公開後）
- スマートフォン対応・オフライン動作（HTMLファイルを直接開けます）

## GitHub Pagesへの公開手順

1. GitHubで新しい**Public（公開）**リポジトリを作成します。
2. リポジトリ直下に `index.html` をアップロードし、`Commit changes` で保存します。この `README.md` は任意です。
3. リポジトリの `Settings` → `Pages` を開きます。
4. `Build and deployment` の `Source` を `Deploy from a branch` にし、ブランチを `main`、フォルダを `/ (root)` にして `Save` を押します。
5. GitHub Pagesの欄に表示された公開URLを開き、動作確認してください。通常は `https://ユーザー名.github.io/リポジトリ名/` という形式です。

ページは一般公開です。身内だけに限定したい場合は `index.html` ファイルを直接送って使ってください。直接開いた場合は「設定URLをコピー」機能は使えません。

## 計算式

無作為・非復元抽出（超幾何分布）です。

- デッキ総枚数 `N`、対象札の合計 `K`、引く枚数 `h`
- 対象を1枚以上引く確率：`1 − C(N−K,h)/C(N,h)`
- 初動札 `S`、事故札 `B` を区別した場合の初動あり・事故なし：`[C(N−B,h) − C(N−S−B,h)] / C(N,h)`
- 初動と事故札を両方引いた手札の残存評価率 `r`：`評価スコア = P(初動あり・事故なし) + r × P(初動あり・事故あり)`

この評価スコアは勝率の推定ではありません。追加カードが初動でも事故札でもないこと、初動札と事故札は重複しないこと、1枚初動であることなどを仮定しています。

## 編集方法

`index.html` はHTML・CSS・JavaScriptがすべて1ファイルに入っています。テキストエディタで編集できます。外部ライブラリ・CDN・API・ユーザーデータの送信はありません。

非公式のファン制作ツールです。カード画像・ロゴ等の権利物は含みません。
